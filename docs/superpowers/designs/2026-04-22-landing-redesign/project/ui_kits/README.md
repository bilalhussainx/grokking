# KairosLearn UI kits

Two artboards presented on one design canvas:

| Artboard | Surface | Fonts | Notes |
|---|---|---|---|
| `Landing — Hero + Scroll Sequence` | Marketing | Cormorant + DM Sans | Full cinematic hero with live neural canvas, scroll-sequence panel, features grid, CTA. Squared, grainy, gold-on-navy. |
| `Product — College Counselor Dashboard` | App | Inter + JetBrains Mono | CC dashboard with sidebar, tool cards, essay studio, school list, activities optimizer, and Coach Kairos drawer. Rounded, black + gold. |

Open `index.html` to view both side-by-side. Each artboard is a self-contained HTML structure inside a `DCArtboard`; focus one fullscreen with the canvas overlay.
