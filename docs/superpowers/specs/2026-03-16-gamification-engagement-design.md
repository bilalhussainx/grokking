# Gamification & Engagement Engine Design Spec

**Date:** 2026-03-16
**Status:** Approved
**Goal:** Make Samsara.ai as addictive as Duolingo + TikTok through XP, gems, streaks, leagues, achievements, variable rewards, AI cards, and always-on hybrid Coach Alex.
**Principle:** Intuitive — users understand the system instantly without tutorials.

---

## 1. Three-Currency System

| Currency | Purpose | Direction | Display |
|----------|---------|-----------|---------|
| XP | Progress metric, league ranking | Only goes up | Level badge in nav |
| Credits | AI feature usage (voice, grading) | Goes down when spent | Amber badge in nav |
| Gems | Cosmetic purchases, streak freezes | Earned & spent | Purple gem icon in nav |

### XP Earn Rates

| Action | XP | Sound |
|--------|-----|-------|
| Open a lesson | +5 | none |
| Complete a lesson | +50 | lesson-complete |
| Answer quiz correctly | +10 | xp-gain |
| Voice session per minute | +20 | none |
| Complete a module | +200 | level-up |
| Complete a course | +1000 | level-up + confetti |
| Daily login | +10 | xp-gain |
| Streak bonus per day | +5 x streak (cap 50) | none |
| "Did You Know?" card read | +5 | none |

### Levels

Level = floor(totalXP / 500). Level 1 = 0-499 XP, Level 2 = 500-999, etc. No cap.

### Gem Earn Rates

| Trigger | Gems |
|---------|------|
| Level up | 10 |
| Weekly leaderboard top 3 | 50 / 30 / 15 |
| League promotion | 25 |
| 7-day streak | 20 |
| 30-day streak | 100 |
| Achievement (common/uncommon/rare/epic/legendary) | 5/10/25/50/100 |

## 2. Streaks (Enhanced)

- Minimum daily activity: 1 lesson opened OR 1 voice session OR 1 quiz answered
- **Streak freeze:** Pro users get 1 free/week. Extra freezes cost 10 gems
- **Streak recovery:** 24h grace period after break, repair for 20 gems
- **Milestones:** 7d→badge+20gems, 30d→rare badge+100gems, 100d→legendary+500gems
- Visual: flame icon in nav, grows/changes color at milestones

## 3. Achievements

5 rarity tiers: Common (gray), Uncommon (green), Rare (blue), Epic (purple), Legendary (gold)

### Starter Achievements
- "First Steps" — complete 1 lesson (Common, 5 gems)
- "Voice Activated" — start 1 voice session (Common, 5 gems)
- "Curious Mind" — ask Coach Alex a question (Common, 5 gems)
- "Consistent" — 3-day streak (Uncommon, 10 gems)
- "Module Master" — complete 1 module (Rare, 25 gems)
- "Polyglot" — start courses in 2+ languages (Rare, 25 gems)
- "Night Owl" — study after 10pm (Uncommon, 10 gems)
- "Early Bird" — study before 7am (Uncommon, 10 gems)
- "Course Graduate" — complete 1 course (Epic, 50 gems)
- "Streak Legend" — 100-day streak (Legendary, 100 gems)
- "Diamond Scholar" — reach Diamond league (Legendary, 100 gems)
- "Voice Marathon" — 30-minute voice session (Epic, 50 gems)

Achievement unlock shows a toast notification with sound + XP fly-up.

## 4. Tiered Leagues

5 leagues: Bronze → Silver → Gold → Platinum → Diamond

- Groups of ~30 users, matched by join date
- Ranked by weekly XP
- Every Monday 00:00 UTC: top 10 promote, bottom 5 demote
- New users start in Bronze
- League badge shown on profile card, nav bar, leaderboard

## 5. Engagement UI

### XP Fly-Up
"+50 XP" golden text animates upward from trigger point, fades after 1.5s. Uses framer-motion.

### Sound Effects
4 sounds in `/public/sounds/`: xp-gain, level-up, achievement, lesson-complete. Global mute toggle stored in localStorage. `useSoundEffect()` hook.

### Confetti
Canvas-confetti on: course complete, league promotion, epic/legendary achievement. 3-second burst.

### "Did You Know?" AI Cards
Between every 2nd lesson in a module. Generated by Moonshot from course material on first view, cached in Supabase. Swipeable on mobile. +5 XP for reading (3s timer). Styled as a glowing card with a lightbulb icon.

### Quiz Cards
After every 3rd lesson. 3 multiple-choice questions from lesson content. Generated by LLM, cached. +10 XP per correct, +30 bonus for perfect. Instant green/red feedback per question.

## 6. Always-On Hybrid Coach Alex

### Lesson Lifecycle

1. **Lesson opens** → Voice connects, Coach greets + previews lesson (30s), voice drops to text mode
2. **User reads** → Coach sends proactive text messages based on scroll position:
   - 25%: encouragement or teaser for upcoming content
   - 50%: key concept highlight
   - 75%: offer to summarize
   - 60s idle: "Still with me?"
3. **User speaks/clicks mic** → Voice reconnects instantly, skips greeting
4. **Lesson complete** → Voice reconnects for celebration + optional quiz

### Variable Teaching Style

Per-lesson random selection (seeded by lessonId + date):
- 60%: Standard (explain, check understanding)
- 20%: Challenge mode (surprise quiz, 2x XP)
- 10%: Story mode (fascinating analogy or story)
- 10%: Speed round (rapid-fire questions, 5 XP each, 10s timer)

### Scroll-Based Text Messages

Pre-generated per lesson (3-4 messages stored in course data). Fallback: generic encouragement from a pool of 20 messages. Appear as Coach Alex chat bubbles sliding in.

## 9. Database

```sql
CREATE TABLE user_xp (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id),
  total_xp INT DEFAULT 0,
  level INT DEFAULT 1,
  weekly_xp INT DEFAULT 0,
  week_start DATE DEFAULT CURRENT_DATE
);

CREATE TABLE xp_transactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  amount INT NOT NULL,
  action TEXT NOT NULL,
  ref_id TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE gem_balance (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id),
  balance INT DEFAULT 0
);

CREATE TABLE gem_transactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  amount INT NOT NULL,
  action TEXT NOT NULL,
  item TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE achievements (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  rarity TEXT NOT NULL,
  icon TEXT,
  criteria JSONB,
  gem_reward INT DEFAULT 5
);

CREATE TABLE user_achievements (
  user_id UUID NOT NULL,
  achievement_id TEXT NOT NULL REFERENCES achievements(id),
  unlocked_at TIMESTAMPTZ DEFAULT now(),
  PRIMARY KEY (user_id, achievement_id)
);

CREATE TABLE league_groups (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  league TEXT NOT NULL DEFAULT 'bronze',
  week_starting DATE NOT NULL,
  member_ids UUID[] DEFAULT '{}'
);

CREATE TABLE user_league (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id),
  league TEXT DEFAULT 'bronze',
  group_id UUID REFERENCES league_groups(id),
  weekly_xp INT DEFAULT 0
);

CREATE TABLE user_cosmetics (
  user_id UUID PRIMARY KEY REFERENCES auth.users(id),
  card_frame TEXT DEFAULT 'minimal',
  card_bg TEXT DEFAULT 'gradient',
  flame_color TEXT DEFAULT 'orange',
  title TEXT DEFAULT NULL,
  purchased_items TEXT[] DEFAULT '{}'
);
```
