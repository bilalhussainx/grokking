## 🎨 Design Tips for Your Deck

### Color Scheme
Use Samsara.ai's existing palette:
- **Background:** Dark navy (#0f172a or similar)
- **Primary:** Blue/Purple gradient accents
- **Text:** White for headings, gray-300 for body
- **CTAs:** Green (Talk), Blue (Learn)

### Typography
- **Headlines:** Bold, large (48-64px)
- **Body:** Clean sans-serif, readable (24-32px)
- **Stats:** Extra large, emphasized (72-96px)

### Screenshot Best Practices
1. **Crop to focus**—remove browser chrome if present
2. **Add subtle shadows** to make screenshots pop
3. **Use arrows/callouts** to highlight key features
4. **Zoom in** on important UI elements
5. **Show mobile AND desktop** to prove responsiveness
