## 🚀 Quick Start — How to Present

### Option 1: Present from Browser (Recommended)

1. **Double-click** `NFX_Samsara_Pitch_Deck.html`
   - It opens in your default browser
2. **Press F11** for fullscreen mode
3. **Use Zoom** (Ctrl + Plus/Minus) to fit your screen
4. **Present!** — Navigate with Page Down/Up or arrow keys

### Option 2: Print to PDF

**Chrome/Edge:**
1. Open `NFX_Samsara_Pitch_Deck.html`
2. Press `Ctrl + P`
3. Destination: "Save as PDF"
4. Layout: Landscape
5. Margins: None
6. Click Save

**Safari:**
1. Open the HTML file
2. File → Export as PDF

### Option 3: Screenshot Each Slide

1. Open `NFX_Samsara_Pitch_Deck.html`
2. Take screenshots of each slide
3. Import into PowerPoint/Google Slides

## 🆘 Troubleshooting

### Images not showing?
The HTML uses relative paths (`tests/screenshots/...`). Make sure:
1. The HTML file is in your project root (`C:\Users\bilal\Downloads\grokking\`)
2. The `tests/screenshots/` folder exists
3. You haven't moved the HTML file to a different folder

### Browser shows blank page?
Try a different browser (Chrome/Edge recommended).

### Need to edit the deck?
Open `NFX_Samsara_Pitch_Deck.html` in any text editor (VS Code, Notepad++, etc.) and modify the HTML/CSS.
