# KairosLearn — Product Marketing Context

> Every marketing agent reads this file before any task. Keep it current.

## What We Do
KairosLearn (kairoslearn.com) is an AI-powered learning platform with voice tutoring in 8 languages, 69+ structured courses across 7 domains, and real-time translated phone calls. Built on Next.js, Deepgram, and OpenRouter (GPT-4o-mini + DeepSeek for coding).

## Brand
- **Name:** Kairos.ai / KairosLearn
- **Domain:** kairoslearn.com
- **Tagline:** "Your AI tutor that speaks your language."
- **Logo:** Navy + gold compass clock (Kairos = Greek for "the right moment")

## Stage
Pre-seed. Live product. Seeking $500K at $2.5M valuation.

## Target Audience
**Primary:**
- CS students (18-28) preparing for coding interviews
- Language learners who want conversation, not flashcards
- Self-taught developers wanting structured paths

**Secondary:**
- EdTech investors, accelerators (DMZ, YC, Techstars)
- Religious studies students (underserved niche — 10 traditions)
- Working professionals upskilling in finance, leadership

## Key Differentiators
1. **Voice AI tutoring** in 8 languages (not chatbot — real conversation)
2. **69+ courses** across CS, languages, religion, finance, philosophy, health
3. **Real-time translated phone calls** between any two languages
4. **$15/month** — 75% cheaper than Coursera, 25% cheaper than Codecademy
5. **Underserved niches** — only platform with AI-coached religious studies
6. **149 Mermaid diagrams** across all courses (interactive visual learning)

## Competitors
| Competitor | Weakness We Exploit |
|------------|-------------------|
| LeetCode | No AI tutor, no voice, coding only |
| Duolingo | Phrases not conversation, languages only |
| Codecademy | $20/mo, no voice, coding only |
| Coursera | $59/mo, passive video, no AI coach |
| Khan Academy | No voice AI, no coding IDE, free but limited |
